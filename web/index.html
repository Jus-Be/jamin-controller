The CSV format follows the WAV Trigger Pro specification: Track, MIDI CH, MIDI Note, Loop, Gain, …

Harmony Classes

A harmony class is a 4-bit bitmask of simultaneously active chord types:

bit 0 = Major bit 1 = Minor bit 2 = Sus2 bit 3 = Sus4

Example: playing a Major and a Minor chord simultaneously → class = 0b0011 = 3.
